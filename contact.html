CONTACT

Contact RegistryReady

Questions, corrections, and concrete feature suggestions are welcome. RegistryReady is a small independent project, so the most reliable contact channel is the public source repository.

Technical issues and corrections

Open a GitHub issue with the page URL, what you expected, what happened, and a minimal example that contains no secrets or personal information. Public reports make it easier to reproduce a problem and let other users see the resolution.

Privacy and advertising questions

For a privacy request or an advertising concern, open an issue titled “Site policy inquiry” in the project repository. Do not include authentication tokens, private configuration, personal identifiers, or confidential company information.

Security reports

If publishing a report would expose users to immediate harm, use the repository owner’s private contact option shown on the GitHub profile rather than posting exploit details publicly. Include only the information needed to reproduce and fix the issue.

Response expectations

Messages are reviewed on a best-effort basis. There is no guaranteed response time, service-level agreement, paid support plan, or telephone support. Spam, link-placement requests, and requests to manipulate search rankings may be ignored.
